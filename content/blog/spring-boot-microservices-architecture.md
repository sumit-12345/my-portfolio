## Introduction

Spring Boot microservices architecture is about building independently deployable components that communicate via APIs. In this post, we cover service discovery, circuit breakers, configuration management, and containerization on Kubernetes.

## Core patterns

- API Gateway
- Distributed tracing
- Centralized logging

## Deployment

Use Helm charts and ArgoCD for GitOps-style Kubernetes deploys.
